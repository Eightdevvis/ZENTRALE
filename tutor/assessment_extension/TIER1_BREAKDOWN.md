# Tier 1: Die 75-Wort-Bootcamp-Basis

## 📊 Zahlen

| Kategorie | Count | Priority | Bedeutung |
|-----------|-------|----------|-----------|
| **Critical** | 13 | 🔴 Must-have | Pronouns, core verbs, questions, basic responses |
| **High** | 25 | 🟠 Essential | Extended verbs, adjectives, connectors |
| **Medium** | 20 | 🟡 Important | Household nouns, family, spatial |
| **Low** | 17 | 🟢 Useful | Greetings, politeness, specific adjectives |
| **TOTAL** | **75** | | Ausreichend für erste Konversation |

## 🔴 Critical (13 Wörter) — Mit diesen kannst du labern

| Wort | Kategorie | Grund |
|------|-----------|-------|
| **ich** | pronoun | "Ich bin..." |
| **du** | pronoun | Direct address |
| **sein** | verb_core | "Ich bin glücklich" |
| **haben** | verb_core | "Ich habe Wasser" |
| **gehen** | verb_core | "Ich gehe dort" |
| **machen** | verb_core | "Ich mache..." |
| **verstehen** | verb_core | "Ich verstehe dich" |
| **wer** | question | "Wer bist du?" |
| **was** | question | "Was ist das?" |
| **wie** | question | "Wie geht's?" |
| **ja** | response | Positive answer |
| **nein** | response | Negative answer |
| **und** | connector | Combine sentences |

**Mit 13 Wörtern möglich:**
```
Ich bin du. (Ich bin ich, du bist du)
Ich verstehe. Ja.
Wer ist du? Wie geht's? Ich mache...
```

→ Nicht perfekt, aber: **funktionale Basis vorhanden**

## 🎯 Learning Path (Empfohlen)

### Session 1-2: Critical Words (13)
- Ziel: Pronouns + core verbs
- Resultat: Können einfache 2-3 Wort Sätze bilden
- Spreed: 0.7x, 1 Wort pro Zug, viel Gestik

### Session 3-5: High Priority (13 + 12 = 25)
- Ziel: Fragen + mehr Verben
- Resultat: Q&A möglich
- Speed: 0.8x, 2 Wörter pro Zug

### Session 6-10: Medium Priority (25 + 20 = 45)
- Ziel: Household + persönliche Referenzen
- Resultat: Kleine Geschichten erzählen
- Speed: 0.9x, 3-4 Wörter pro Zug

### Session 11-14: Low Priority (45 + 17 = 62+)
- Ziel: Polish, Edge Cases, Articles
- Resultat: ≥75% Mastery, ready for spawn
- Speed: 1.0x, natürliche Konversation

**Timeline:**
- 3x/Woche Sessions
- ~4-5 Wochen total
- ~12-15 Sessions für ~75% Mastery

## 📈 Mastery Calculation

```
Tier1_Mastery = (confirmed_tier1_words / 75) * 100

Level 0-25%:    "Absolute beginner, single words"
Level 25-50%:   "Can do 2-3 word phrases"
Level 50-75%:   "Can ask questions, tell simple stories"
Level 75-100%:  "SPAWN! Ready for conversation"

Spawn Trigger: ≥75% = ~56 words confirmed
```

## 💡 Why 75 & not 50 or 100+?

**Too few (50 words):**
- Questions: nur wer/was/wie, keine wann/warum
- Can't talk about personal stuff (no family words)
- Can't narrate (no time words)
- Spark frustration fast

**Too many (100+ words):**
- Bootcamp takes 8-12 weeks (slow)
- Burnout risk
- Your USP is **speed**
- Better to spawn at 75 + learn Tier 2 in conversation

**75 is sweet spot:**
- Covers critical + high priority completely
- Gives household context + personal relevance
- ~4-5 weeks aggressive learning
- Ready for **real exchange**
- Tier 2 vocab comes naturally from conversation
