# Python-Abhaengigkeiten fuer einen AUSSENPOSTEN (Pi an der Wand).

# stehen faster-whisper, sherpa-onnx, piper-tts, cryptography, fsrs, openai —

# Pi 3 (armv7l, 1 GB RAM) waeren sie nicht nur nutzlos, sondern ein langer,
# schmerzhafter Build aus dem Quellcode.
#
# Installieren: .venv/bin/pip install -r deploy/requirements-aussenposten.txt
# (scripts/deploy_pi.sh nimmt im Aussenposten-Modus automatisch diese Datei,
# scripts/pi_autopull.sh ebenfalls, wenn die Marker-Datei .aussenposten liegt)
